1. 알고리즘 설명

다익스트라

요약: 가중치가 있는(음의 가중치 X) 방향(또는 무방향) 그래프에서 한 특정 정점에서 다른 모든 정점으로 가는 최단경로를 구한다. 그리디 알고리즘의 일종이다.

알고리즘의 설명:

  1. 다른 모든 정점에 대한 최단 경로를 알고 싶은 특정 정점을 선택한다. 시작 정점에 대한 비용을 0으로 두고 나머지를 무한대(늘 큰 수)로 두어서 1~2 반복문에 돌입했을 때 시작 정점이 곧바로 선택되도록 한다.
  2. 시작 정점으로부터 기록된 누적 비용이 가장 낮은 미방문 정점을 선택한다. 선택된 정점은 최단거리가 확정되어 방문 정점이 된다.
  3. 새로 선택한 정점을 통했을 때에, 새로 갈 수 있는 경우와 기존보다 비용이 낮아지는 경우를 기록한다. 동시에 과정을 기록하여 최단 경로의 직전 정점도 기록한다.
  4. 시작 정점으로부터 도달 가능한 모든 정점을 선택할 때까지 1번과 2번 과정을 반복한다.

어떤 자료구조를 이용하여 구현하느냐에 따라서 결과는 같으나 알고리즘의 시간복잡도가 조금씩 달라진다. 정점 간의 연결과 가중치를 나타낼 때에 인접행렬을 사용하느냐, 인접리스트를 사용하느냐도 다르고, 다음에 선택할 최소 비용 정점을 단순 배열 탐색으로 찾느냐, 우선순위 큐로 찾느냐에 따라서도 달라진다

음의 가중치가 허용되지 않는데, 해당 알고리즘은 그리디하게 진행되어 각각의 정점에 대한 최단 거리를 과정 중에 확정하기에, 그 이후에 음의 가중치를 가진 간선을 통과하여 비용이 감소할 일이 있어서는 안되기 때문이다.

벨만-포드

요약: 가중치가 있는(음의 가중치 허용) 방향(당연히 무방향도 포함한다) 그래프에서 한 특정 정점에서 다른 모든 정점으로 가는 최단경로를 구한다. 음의 가중치 순환, 즉 음수 사이클을 감지할 수 있다. 동적 계획법 알고리즘의 일종이다.

알고리즘 설명:

  1. 다른 모든 정점에 대한 최단 경로를 알고 싶은 특정 정점을 선택한다. 시작 정점에 대한 비용을 0으로 두고 나머지를 무한대(늘 큰 수)로 두어서 1~2 반복문에 돌입했을 때 연산이 곧바로 시작되도록 한다.
  2. 그래프 내에 존재하는 모든 간선을 순회한다. 출발 정점으로부터의 누적 비용이 무한대가 아니면서, ‘출발 정점의 누적 비용 + 간선 가중치’가 도착 정점의 기존 기록보다 낮아지는 경우를 확인한다.
  3. 기존보다 비용이 적어지는 경우, 도착 정점의 누적 비용을 갱신한다. 동시에 과정을 기록하여 최단 경로의 직전 정점도 기록한다.
  4. 도달 가능한 모든 간선에 대해 1번과 2번 과정을 (정점의 개수 - 1)번 반복한다. 해당 반복 기간 도중에 갱신되는 값이 없다면, 조기 종료가 가능하다.
  5. 반복이 끝난 이후, 한번 더 모든 간선에 대해 1, 2번 과정을 실행한다. 이때에 비용 갱신이 이뤄진다면, 시작 정점에서 도달 가능한 그래프 내에 음수 사이클이 존재한다고 판단할 수 있다. (예외적으로, 시작 정점에서 도달이 불가능하다면, 판단 자체를 할 수 없을 것이다.)

(정점의 개수 - 1)개의 반복은, 음수 사이클이 없을 때에 그래프에서 최단 경로를 구성할 때에 필요한 간선의 최대 개수가 (정점의 개수 - 1)개이기 때문이다. 한 정점과 다른 정점이 이어질 수 있는 최단 경로의 간선의 최대 개수이기 때문이므로, 그 이후로도 감소가 발생한다면 음수 사이클이 존재함을 발견할 수 있다.

2. 핵심 코드

다익스트라

다익스트라: 인접 리스트와 우선순위 큐(최솟값)를 이용한 구현이다.

DIJKSTRA(G, s): //G란 그래프로 정점의 집합인 V와 인접리스트 Adj를 포함한다.

    for each vertex v in V:
        dist[v] = INF //정점 v까지의 최단 거리 기록. 무한대로 초기화.
        prev[v] = NIL //정점 v직전의 정점을 기록. 비워 둔다.
        visited[v] = false //정점 v의 최단 거리가 확정됨을 기록. false로초기화

    dist[s] = 0 //시작 정점은 자기 자신이 출발이므로 최단 거리가 0이다.

    Q = empty min-priority queue //우선순위 큐. 최소 값을 맨 위로 올린다.
    Q.insert(0, s) //반복을 시작하기 위한 준비. 시작 정점과 비용 0을 큐에 넣는다

    while Q is not empty:
        (cost, u) = Q.extractMin //큐에서 비용이 가장 낮은 것을 꺼낸다.
        if visited[u]: //만약 이미 방문한 정점이라면 건너뛴다.
            continue
        visited[u] = true //그렇지 않다면, 새로 방문한 정점이 된다.

        for each edge (u, v, w) in Adj[u]:
            //인접 리스트에서 새로 합류한 정점을 통해 최단 경로를 업데이트 한다.
            if visited[v] == false and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                prev[v] = u
                Q.insert(dist[v], v)
                //동일한 정점이 이미 있어도 넣는다. 이후 적절히 필터링된다.

    return dist, prev //최단 길이와 그 경로를 복원하는 정보를 리턴한다.

벨만포드

BELLMAN_FORD(G, s): //G 그래프에는 V, E 등의 정보를 모두 포함하고 있다.

    for each vertex v in V:
        dist[v] = INF //정점 v까지의 최단 거리 기록. 무한대로 초기화.
        prev[v] = NIL //정점 v직전의 정점을 기록. 비워 둔다.

    dist[s] = 0 //시작 정점은 자기 자신이 출발이므로 최단 거리가 0이다.

    for i = 1 to |V| - 1: //정점개수 - 1 번 만큼 반복한다.

        changed = false //최단 거리 갱신 여부를 기록한다.

        for each edge (u, v, w) in E: //매번 모든 간선을 체크한다.

            if dist[u] != INF and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                prev[v] = u
                changed = true
                //갱신이 필요한 경우에 진행한다.

        if changed == false:
            break //변화가 없다면 더 이상의 갱신이 불필요하므로 중단한다.

    for each edge (u, v, w) in E: // 음수 사이클을 감지하는 과정이다.

        if dist[u] != INF and dist[u] + w < dist[v]:
            return "Reachable Negative Cycle"
            //가능한 끝단의 정점 사이의 경로까지도 확인했음에도 갱신이 필요하다면,
            //시작 정점에서 도달 가능한 음수 사이클이 존재함을 의미한다.

    return dist, prev //최단 길이와 그 경로를 복원하는 정보를 리턴한다.

3. 복잡도 비교

우선 각 알고리즘을 구현한 방식을 명확하게 하겠다.

다익스트라 : 인접 리스트 + 우선순위 큐(이진 최소 힙)
벨만포드 : 간선 목록(배열) + 거리 배열

표를 통해 우선 정리한다.

비교 항목다익스트라벨만-포드
시간복잡도O((V+E) log V)O(VE)
공간복잡도O(V+E)O(V+E)

V는 주어진 그래프의 정점의 개수, E는 주어진 그래프의 간선의 개수를 의미한다.

다익스트라

-시간 복잡도를 따지기 위해서 최악의 경우를 가정한다. 단위 연산마다의 경우를 살펴본다.

정점 초기화: 상수 시간 연산을 모든 정점에 대해 수행한다. 따라서 O(3V) = O(V)이다.

for each vertex v in V:
    dist[v] = INF //정점 v까지의 최단 거리 기록. 무한대로 초기화.
    prev[v] = NIL //정점 v직전의 정점을 기록. 비워 둔다.
    visited[v] = false //정점 v의 최단 거리가 확정됨을 기록. false로초기화

우선순위 큐 추출: 이진 힙으로 구현되어 있으므로, 힙 속에 원소가 A개라면, 삽입과 추출에 각각 O(logA)의 시간복잡도를 가진다.

알고리즘에서 큐 속에 들어있을 수 있는 정점들의 개수를 고려한다. 큐에 정점을 넣는 순간은 어느 한 정점에 대한 거리 갱신이 발생할 때이므로, 새로 삽입되는 후보의 수는 해당 정점의 밖으로 나가는 간선의 개수 이하이다. 최악의 경우이므로, 모든 정점이 서로 모두 연결되어 있는 상황을 가정한다면, 큐의 삽입과 추출에는 O(logE) 가 E번 일어나므로, O(ElogE)의 복잡도를 가진다. (간선이 0개인 경우를 고려하여 E+1을 사용할 수 있겠으나, 해당 경우를 고려하지 않겠다. 간선이 없다면 알고리즘 사용이 무의미하기 때문이다.)

while Q is not empty:
    (cost, u) = Q.extractMin //큐에서 비용이 가장 낮은 것을 꺼낸다.
    if visited[u]: //만약 이미 방문한 정점이라면 건너뛴다.
        continue

인접리스트를 통한 거리 갱신: 새롭게 방문한 정점의 인접리스트를 순회한다. 모든 정점은 한 번씩만 선택되므로, 최악의 경우, 모든 간선에 대한 검사가 E번 이뤄진다. 순회 과정에서, 간선 하나를 if문에 따라 검사하고 갱신 여부를 판단하는 것은 상수 시간이 걸리고, 큐 삽입에는 상술했듯 O(logE)의 시간복잡도를 가진다. (큐 안의 최대 정점 개수가 E개이므로.) 정리하면 E * ( O(1) + O(logE)) = O(E) + O(ElogE) 가 된다.

for each edge (u, v, w) in Adj[u]:
    //인접 리스트에서 새로 합류한 정점을 통해 최단 경로를 업데이트 한다.
    if visited[v] == false and dist[u] + w < dist[v]:
        dist[v] = dist[u] + w
        prev[v] = u
        Q.insert(dist[v], v)

세 시간복잡도를 합산해보면

O(V) + O(ElogE) + O(E) + O(ElogE) = O(V + ElogE)로 요약 가능하다. 여기서 단순 그래프라고 그래프를 가정하면, 정점이 V개 일 때, 존재 가능한 최대 간선 수 E는 V * (V-1)이므로, E의 개수는 V^2 의 수준을 넘지 않는다. 즉 E = O(V^2)가 성립한다. log(E) <= log(c*V^2) = logc + 2logV = O(logV) 가 된다. 따라서 O(V + ElogE) = O(V + ElogV)가 된다. 묶어서 표현하기 위해 V <= VlogV 상한을 이용하면 O(V + ElogV) ⊆ O((V+E)logV) 로 표현할 수 있다.

벨만포드

-시간 복잡도를 따지기 위해서 최악의 경우를 가정한다. 단위 연산마다의 경우를 살펴본다.

정점 초기화: 상수 시간 연산을 모든 정점에 대해 수행한다. 따라서 O(2V) = O(V)이다.

for each vertex v in V:
    dist[v] = INF //정점 v까지의 최단 거리 기록. 무한대로 초기화.
    prev[v] = NIL //정점 v직전의 정점을 기록. 비워 둔다.

전체 간선 순환 및 거리 갱신: 바깥쪽 반복문은 최대 V-1회 반복한다. 내부 반복문은 그래프의 모든 간선을 한 번씩 순회한다. 즉 E번 반복한다. 따라서 (V-1)*E 번의 반복이 발생하고, 반복문 내부의 모든 작업은 상수 시간에 수행할 수 있으므로 O((V-1)E) 의 시간 복잡도를 가진다.

for i = 1 to |V| - 1: //정점개수 - 1 번 만큼 반복한다.
    changed = false //최단 거리 갱신 여부를 기록한다.

    for each edge (u, v, w) in E: //매번 모든 간선을 체크한다.
        if dist[u] != INF and dist[u] + w < dist[v]:
            dist[v] = dist[u] + w
            prev[v] = u
            changed = true
            //갱신이 필요한 경우에 진행한다.

    if changed == false:
        break //변화가 없다면 더 이상의 갱신이 불필요하므로 중단한다.

음수 사이클 검사: 마지막 한 번의 검사 과정에서 모든 간선에 대한 탐색이 한 번더 발생하므로, O(E)이다.

for each edge (u, v, w) in E: // 음수 사이클을 감지하는 과정이다.
    if dist[u] != INF and dist[u] + w < dist[v]:
        return "Reachable Negative Cycle"

세 시간복잡도를 합산해보면

O(V) + O((V-1)E) + O(E) = O(V + VE)로 요약 가능하다. 여기서 간선이 하나 이상인 보통의 그래프를 생각하면, O(VE)로 간략하게 표현할 수 있다.

다익스트라

-공간 복잡도를 따지기 위해서 최악의 경우를 가정한다. 사용되는 자료구조를 살펴본다.

인접 리스트는 그래프의 모든 정점과 간선이 저장되어 있으므로 O(V+E)의 공간을 사용한다. 우선순위 큐에는 앞서 언급했듯, 간선의 개수만큼이 최대로 삽입될 수 있으므로, O(E)의 공간을 사용한다. 따라서 공간 복잡도를 O(V+E)라 표현할 수 있다.

벨만포드

-공간 복잡도를 따지기 위해서 최악의 경우를 가정한다. 사용되는 자료구조를 살펴본다.

간선 목록은 그래프의 간선을 저장하므로 O(E)의 공간을 사용한다. 거리 배열과 직전 정점 배열은 각각 정점을 저장하므로 정점의 개수에 비례하여 O(V)의 공간을 사용한다. 따라서 전체 공간복잡도는 O(V+E)라 표현할 수 있다.
